## 🧠 Théorie principale

**Thèse :** Le patriarcat a besoin de détruire l'amour authentique pour maintenir son pouvoir.

**Preuve expérimentale :** Un parcours personnel de violence → automutilation → rencontre amoureuse → arrêt immédiat → censure → psychose → construction politique → guérison partielle par l'amour collectif.

**Sources :** bell hooks (*Feminism is for Everybody*), Jinéologie (Abdullah Öcalan/Rojava), mouvements féministes palestiniens, théories trans radicales.
